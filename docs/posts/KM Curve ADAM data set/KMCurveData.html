The endpoint is Time to First Dermatologic Event (skin reactions at the patch site). The R Consortium submitted this same KM figure to the FDA in its R-based Submission Pilot 3, and the ADaM data behind it was built with {admiral}. So this isn’t a toy example.

## The data
We will use the **CDISC Pilot study (CDISCPILOT01)**, a public mock Alzheimer's trial of xanomeline patches vs. placebo. It ships as R data frames in the [`{safetyData}`](https://github.com/SafetyGraphics/safetyData) package, so anyone can reproduce this post.

The endpoint is **Time to First Dermatologic Event** (skin reactions at the patch site). The [R Consortium submitted this same KM figure to the FDA](https://github.com/RConsortium/submissions-pilot3-adam-to-fda) in its R-based Submission Pilot 3, and the ADaM data behind it was built with `{admiral}`. So this isn't a toy example.
